## How to read this

- **Power.** Battery rows measure system power as battery voltage x current. AC rows estimate it as USB input minus charge current, so their watts are not comparable with battery rows. Compare power only between battery rows.
- **Device settings.** EAS = the kernel's Energy Aware Scheduling with no sched_ext scheduler loaded. boostd is the SM8550 boost daemon (RP6, Thor). LAVD is the sched_ext scheduler the Pocket FIT used before EAS became its default. GPU ranges are the devfreq min-max at session start; the Pocket FIT's 462 MHz floor in some rows is a start-of-session transient, and every measured run saw 231 MHz.
- **Software stack.** All SteamOS rows: SteamOS 0.3.0 (build 20260922), Proton 11 ARM64 (proton-11.0-2c) running the 32-bit x86 game through FEX and Wine WoW64, Turnip from Mesa 26.3-devel. Android rows: Android 13 (RP6 firmware V1.0.0.406), kernel 5.15 GKI, Proton 10 arm64ec in GameNative 1.2.1, display at 120 Hz. GameNative was set to Turnip, but the report records the system Qualcomm driver.
- **Android gaps.** The Android rows have no vkmark result (the harness only runs Tomb Raider there). Their graphics settings were not set by the harness, so equal presets are assumed, not verified. Device settings come from the vendor stack (WALT governor, perf HAL), not from us.
